
# Інтег. БД

## 1. Основні можливості

- Зберігання станцій моніторингу.
- Зберігання погодинних вимірювань.
- Автоматичне оновлення існуючих записів.
- Захист від дублювання даних.
- Партиціювання часових рядів за місяцями.
- Зберігання нормативів, інцидентів та підписок.

## 2. Інтеграція зі Open-Meteo API

Для збереження нормалізованих вимірювань: app.services.record_writer.save_records

Ex:

from datetime import datetime, timezone
from decimal import Decimal
from app.services.record_writer import save_records

records = [
    {
        "station_id": 1,
        "recorded_at": datetime(
            2026, 11, 12, 10, 0,
            tzinfo=timezone.utc
        ),
        "pm2_5": Decimal("15.40"),
        "pm10": Decimal("22.10"),
        "no2": Decimal("12.50"),
        "o3": Decimal("30.00"),
        "co": Decimal("150.00"),
        "aqi": 45
    }
]

save_records(records)

Час вимірювання передається у форматі datetime з часовим поясом UTC. Функція приймає список словників. Усі поля прикладу повинні бути присутніми; відсутні показники можуть мати значення None. У разі повторного надходження даних за той самий час та станцію існуючий запис оновлюється.

## 3. Важливо

Місячні партиції створені на 2026–2028 роки. Для наступних періодів потрібно буде реалізувати автоматичне створення нових партицій.

Значення порогів забруднення необхідно ще буде узгодити.
