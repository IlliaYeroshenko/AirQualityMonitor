# Air Quality Monitor

## Курсовий проєкт №7

**Тема:** Сервіс екологічного моніторингу якості повітря, агрегація часових рядів та алертинг аномалій.

### Модуль бази даних

Модуль реалізовано мовою Python з використанням PostgreSQL, SQLAlchemy та Alembic.

**Реалізовані можливості:**
- Створення семи основних таблиць бази даних.
- Зберігання станцій моніторингу та їхніх координат.
- Зберігання погодинних екологічних показників.
- Індексація та партиціювання часових рядів за місяцями.
- Захист від дублювання вимірювань.
- Пакетне збереження даних за допомогою UPSERT.
- Початкове заповнення бази даних містами та демонстраційними порогами забруднення.

### Встановлення

Для запуску необхідні Python, Docker Desktop і Docker Compose.

1. Створити віртуальне середовище:

```powershell
py -m venv .venv
```

2. Встановити залежності:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. Створити файл `.env` на основі `.env.example` та встановити однаковий пароль PostgreSQL у відповідних параметрах.

4. Запустити базу даних:

```powershell
docker compose up -d
```

5. Виконати міграції:

```powershell
.\.venv\Scripts\alembic.exe upgrade head
```

6. Додати початкові дані:

```powershell
.\.venv\Scripts\python.exe -m scripts.seed_stations
.\.venv\Scripts\python.exe -m scripts.seed_thresholds
```

### Підключення до бази даних

- PostgreSQL: `localhost:55432`
- Adminer: `http://localhost:8081`
- База даних: `air_monitor`

Облікові дані визначаються файлом `.env`.

### Інтеграція з іншими модулями

Open-Meteo.

Для збереження підготовлених вимірювань використовується функція:

`save_records(records)`

Модуль розташований у файлі:

`app/services/record_writer.py`

Кожен запис повинен містити `station_id`, `recorded_at`, `pm2_5`, `pm10`, `no2`, `o3`, `co` та `aqi`. Час передається як Python `datetime` із часовим поясом UTC.

Повторне збереження даних за однаковий час і станцію оновлює наявний запис.

### Важливі примітки
- Створено місячні партиції за 2026–2028 роки. Для наступних років потрібно передбачити автоматичне створення нових партицій.
- Партиція `DEFAULT` використовується для дат поза створеними місячними діапазонами.
